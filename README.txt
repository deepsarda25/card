SHahi Patra invitation replica

Run locally from this folder:
  python3 -m http.server 8000

Open http://localhost:8000/

Edit data in templates/royale/local-data.js. To use the on-page editor, open http://localhost:8000/templates/royale/index.html?edit=1. The editor stores changes in this browser's local storage. If you edit local-data.js later, reload the page; the file data takes priority over editor saves made before that file change.
